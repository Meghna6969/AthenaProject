Hello! This project is my submission towards 2025 athena award. I have made most famous game Rock Paper Scissors, but just to add a twist also got the famous big bang version of the game. I initally make the game in just html and css. Then wanted to do the same in 3d, I never did 3d and some people told me its going to be easy if you do the 2d version first, which is no true at all 💀. Both the platforms are completely different and I just realized it after making this project. The 3d version of the game is made with Three JS and vanilla js. There was some AI used in the project to guide me with 3d stuff. You can play the game here: https://meghna6969.github.io/AthenaProject/3dversion.html !
